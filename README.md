# 📚 Speakout 3rd B1+ — مركز التعلّم التفاعلي

موقع كامل متكامل لماتيريالك الخاصة: كتاب **Speakout 3rd Edition B1+** + كل الصوتيات + فيديوهات BBC — بواجهة عربية عصرية، مشغل صوت ذكي، وفوريَر PDF مدمج لصفحات الكتاب.

## 🚀 التشغيل (خطوة واحدة)

1. دوس **دوبل كليك** على `Start-Website.bat`
2. هيبدأ سيرفر محلي ويفتح المتصفح على:
   **http://127.0.0.1:8123/**
3. سيب نافذة الباتش مفتوحة وأنت بتذاكر (اقفلها بس لما تخلص).

> ⚠️ لو مفيش شاشة براوزر اتفتحت: افتح المتصفح بنفسك واكتب العنوان: `http://127.0.0.1:8123/`

## 🗺️ إيه اللي جوّه الموقع؟

| القسم | الوصف |
|---|---|
| 🏠 الرئيسية | كروت الوحدات الثمانية + إحصائيات + حالة تقدّمك |
| 📚 فهرس الكتاب | الفهرس المطبوع للكتاب (وحدة وحدة) بروابط مباشرة |
| 🚩 وحدة (1–8) | بانر الوحدة + سؤال الـ Vlog + أهداف التعلّم + تِبس لكل درس: **A / B / C / D / Review / Vocab Bank / Mediation** |
| 🎧 مكتبة الصوت | كل الـ 81 مسار صوتي + كيو تشغيل + سرعة + تكرار + "خلصت" |
| 🎬 مكتبة الفيديو | 16 فيديو BBC (Vlogs / Street Interviews / Programmes) |
| 📝 السكربتات | ملفا Audioscripts + Videoscripts بصيغة PDF مدمجة |
| 📖 الكتاب كامل | الـ PDF الأكاديمي الأصلي (136 صفحة) بتكبير وقفز |

### في كل درس (مثال 1A)
- 📄 زر **"افتح صفحات الدرس"** — يعرض صفحات الكتاب الحقيقية (مثال: الدرس 1A = صفحات مطبوعة 8–10)
- 🎧 الصوتيات مرتبة زي التمارين: `Audio 1.01`, `1.02` ...
- 🎬 درس D فيه فيديو BBC الخاص بالوحدة
- ✅ علامة "خلصت" لكل مسار + تقدم الوحدة يتحدث لحظيًا (محفوظ في متصفحك)

## 🧰 ملحوظات فنية

- **صفحات ناقصة؟** الـ PDF عندك مقصوص: فهرس الوحدات 1–8 كامل، لكن ملف `student-book.pdf` هنا مابعد-الوحدات بيقفل عند صفحة PDF 136 (بنك المفردات يكمل عنده Quest U7–U8 وصفحات الـ Mediation Bank مش موجودة في الملف الفعلي). الصوتيات بتاعتها المرفقة (VB/MB) شغالة عادي من "مكتبة الصوت" و"تباس المردود" تبع الدرس.
- **الإيزاحة صفحات الكتاب**: الترقيم المطبوع = رقم الـ PDF − 1 (مثلاً مطبوع ص8 = PDF ص7). كله محفوظ في `js/data.js`.
- **واجهة عربية RTL** + خط Cairo للعربي و Poppins للإنجليزي (متغطية ومحليتان O's).
- بيانات الملفات الصوتية/الفيديو مقروءة من `js/manifest.js` (متولدة أوتوماتيك من فولدراتك الحقيقية).
